Copying into OneNote or Wartburg

Open an article, press Ctrl+A, then Ctrl+C, and paste into a OneNote page or the Wartburg editor. Headings, lists, tables and code blocks come across. The Markdown files in the docs folder are the source: edit those, then run node docs\build-docs.js to rebuild these pages.
